# 喵喵的逆袭战斗模拟器

一个纯后端的离线战斗模拟器，用于批量比较“喵喵的逆袭”的猫咪编队、等级、上场顺序、经济节奏和补位策略。模拟器不渲染 UI，不访问游戏服务器，也不会消耗真实无尽次数。

## 能力

- 0.02 秒固定步长复现移动、攻击前摇、冷却、闪避、暴击、护甲、范围伤害、召唤与猫塔结算。
- 支持凤凰回血、时空冻结、直接冰冻、抗冻、热浪、满月、重力、浓雾、沙暴、怒气与免控。
- 支持当前已开放的第 3–4 章机制，包括锚定、暖光環、破甲啃咬、冲锋、跃过前排、灼烧、砲台、召唤与海市蜃樓／商隊／寶藏駱駝关卡事件。
- 支持自动钱包升级、严格固定的上场序列、指定场上数量、后期炮灰补位和战斗道具。
- 支持单局复现、固定种子批量、多个候选方案对比及多线程 worker。
- 支持用 `--trace` 导出 0.02 秒动作时间线，并从 `policy.actions` 精确回放。
- 输出存活时间、轮次、Boss 伤害、猫塔生命、伤害、治疗、击杀、死亡时间、部署次数和最终场上构成。

## 环境

- Node.js 20 或更高版本。
- 运行时不依赖 npm 包。
- 可选：刷新数据时使用 Python 3 和本机 Camoufox 调试浏览器。

## 快速开始

```bash
npm test

npm run simulate -- run examples/endless-current.json --seed 1 --format table

npm run simulate -- batch examples/endless-current.json \
  --runs 30 --jobs 8 --format table

npm run simulate -- compare examples/endless-compare.json \
  --runs 30 --jobs 8 --format markdown
```

常用数据检查：

```bash
npm run simulate -- cats --tier S
npm run simulate -- waves --stage-id 9101
```

完整场景字段、自动策略、定时动作和输出定义见 [docs/scenario-schema.md](docs/scenario-schema.md)。

## 数据快照

`data/snapshot.json` 采集于 2026-11-13，当前为第 9101 号无尽关卡、2026-11-09 至 2026-11-15 赛季的「滿月」84 波数据。图鉴共 32 只猫、56 种老鼠和 40 个已开放关卡（第 1–4 章）。快照只保留公开图鉴、关卡和赛季元数据，不保存账号拥有状态、最佳成绩、剩余次数或身份信息；借住家貓提供的额外队伍栏位同样不会写入快照，需要时由场景或命令行显式声明。

在已登录游戏并打开 Camoufox 调试标签页时，可以只读刷新：

```bash
python3 tools/capture_live.py
```

采集器默认调用本机的 `camoufox-remote-control` BiDi 客户端。其他环境可通过 `BIDI_CLIENT` 环境变量指定兼容客户端路径。刷新后必须重新运行 `npm test`。

## 页面导出与策略执行器

[`tools/ilovecat-workbench.user.js`](tools/ilovecat-workbench.user.js) 是可选篡改猴脚本，适合不便频繁启动 Camoufox 时手动导出当前数据。安装后打开游戏战斗页，页面右上角会出现“喵喵的逆袭工具”：

- 复制或下载前按需勾选图鉴、已拥有猫咪等级、当前无尽、当日每日任务四档难度和正在进行的限时全服头目；所有导出项默认关闭，每日任务、固定关卡和 JS 源码的父项由后续选择或输入自动联动，手动取消父项会清空对应内容；每日任务四档难度收在一行；
- 策略信息固定显示名称、适用关卡和“猫咪名称(等级)”配队，配队统一按 C/B/A/S 等级排序并着色；执行时每只猫的实际等级大于等于策略要求即可，低于要求时拦截；校验结果在下方单独显示，并以绿、黄、红三种颜色区分成功、警告和错误；
- 顶部拆为“在线策略”和“本地策略”两个入口，均不接受粘贴 JSON。在线页加载时居中提示且隐藏刷新按钮，加载后用刷新图标和关卡标签筛选策略，每次只显示一个关卡；选中策略后自动校验并展开配队与说明，配队颜色和顺序与校验摘要一致，未选中项只显示标题与标签。在线列表不再显示索引统计行。索引条目可选 `expiresAt`，到期后不再显示或执行；无尽策略默认在下周一 00:00（`+08:00`）过期。本地页只允许选择 JSON 文件，选定后同样自动校验；“开始执行”复用同一套校验逻辑，校验错误附近提供重新校验的刷新图标按钮；
- 所选 JSON 的 `snapshot` 字段就是模拟器 `data/snapshot.json` 所需结构；可单独提取，账号信息或 JS 不会混入其中；
- 自动开始战斗默认勾选，执行倍速默认“自动”，静默执行默认关闭；点“开始执行”后，自动开始战斗可能消耗 1 次挑战。执行倍速可选 1x、2x、3x 或自动；静默执行会在校验通过并开始战斗时隐藏悬浮按钮和面板；自动执行会隐藏界面，等待下一场符合策略的新战斗。隐藏后战斗结束不会自动恢复，需从篡改猴菜单“重新打开脚本面板”恢复。脚本会在篡改猴存储中只保留最近一局复核包，可从同一菜单导出；复核包捕获开战/结束接口原始数据、种子、队伍、道具、动作和最终引擎快照。执行器通过页面按钮升级钱包、部署猫咪和发射猫爪炮；猫爪炮可配置最早开炮时间与最少炮口目标数，避免前中期空放；
- 导出不会上传数据，也不会写入 UID、Cookie、令牌、罐罐余额、通关/星级或抽卡信息。

完整安装说明、策略字段和执行边界见 [docs/tampermonkey-tool.md](docs/tampermonkey-tool.md)。

## 可信度与边界

战斗逻辑依据 2026-11-13 客户端战斗块 `72530.5c0ecaec31.js`，其 SHA-256 为 `49c0709150d1f4b41848c62bac2c125418e0aab7c395ae224e5e433fed78fb30`。项目通过同版本隔离重放、实战观测和固定种子回归测试校准关键公式。

当前验证边界是公开图鉴中的第 1–4 章、第 9101 号无尽模式和快照内已出现的鼠种。更新日志提到的第 10 章及图鉴中尚未进入公开关卡的后续鼠种只有部分通用代码准备，不能据此宣称第 5 章以后已被完整校准。

模拟器不覆盖服务器权威校验、计分、反作弊、隐藏未来配置和玩家反应延迟。相同 seed 只复现本模拟器的随机序列，不代表服务器抽到的随机序列。自动补位没有人工操作延迟，因此结果通常比手动实战乐观。

本项目是独立研究工具，与游戏运营方无隶属关系。
